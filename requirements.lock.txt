# requirements.txt 는 하한선(>=)만 있어서 설치 시점에 따라 다른 버전이 깔린다.
# 그런데 models/ 의 pickle 번들은 라이브러리 클래스를 통째로 담고 있다:
#   smp_binary.pkl   → lightgbm.sklearn.LGBMClassifier

# lightgbm·scikit-learn 버전이 어긋나면 경고만 뜨고 넘어가거나, 최악의 경우
# unpickle 자체가 실패해 SMP·태양광 서빙이 죽는다.  그래서 배포는 이 파일로 한다.
#
#   ★ torch 는 반드시 CPU 휠을 먼저 깔 것 (안 그러면 CUDA 2~3GB 를 끌고 온다):
#       pip install torch==2.10.0 --index-url https://download.pytorch.org/whl/cpu
#       pip install -r requirements.lock.txt
#
# 재학습으로 모델을 새로 굽거나 라이브러리를 올릴 때는 이 파일도 함께 갱신한다.
